# 04 · 数据与隐私

## 一句话结论

**分发物里没有任何用户数据。** 把 `ts-translate.html` 发给任何人，对方打开都是全新空白的出厂状态。

## 数据存在哪

| 数据 | 存放位置 | 会不会随文件走 |
|---|---|---|
| 云 API 密钥与配置 | 浏览器 localStorage（`ztw_config`） | 否 |
| 术语库 | 浏览器 localStorage（`ztw_glossary`） | 否 |
| 规则库（特殊词条 / 正则规则 / 大小写规则） | 浏览器 localStorage（`ztw_rules`） | 否 |
| 语种列表 | 浏览器 localStorage（`ztw_langs`） | 否 |
| 术语库导入记录 | 浏览器 localStorage（`ztw_import_log`） | 否 |
| TS 生成结果记录 | 浏览器 localStorage（`ztw_ts_gen_log`） | 否 |
| 翻译范围与界面状态 | 浏览器 localStorage（`ztw_ts_scope` / `ztw_ui`） | 否 |
| 已翻译字符数 / 免费额度 | 浏览器 localStorage（`ztw_usage` / `ztw_quota`） | 否 |
| 「默认下载路径」授权句柄 | 浏览器 IndexedDB（库 `ztw_fs`，表 `dirs`） | 否 |
| 上传的 `.ts`、导出的 Excel | 只在内存与你的下载目录里 | 否 |

- 源文件 `src/ts-translate.html` 里只有**出厂常量**（默认配置、默认规则库、示例词条），没有任何一条真实数据。
- 首次打开时注入的示例词条，也只写进**当前浏览器**的存储，不回写文件。
- 出于安全策略，部分数据在解析失败或结构异常时会先写一份 `<键名>_backup` 备份，再回落默认值。

## 网络行为

| 行为 | 目的地 | 是否经过我们的服务器 |
|---|---|---|
| 调用翻译 | 你所选服务商的官方 API（阿里云 / 腾讯云 / 百度 / 有道 / 你自填的 AI 接口），由你的浏览器直连 | 否，本工具不含任何后端 |
| 「默认下载路径」写文件 | 你本机授权的文件夹 | 不涉及网络 |
| 加载页面 | 本地文件 / 内网静态服务器 | 不涉及外网 |

签名在浏览器里完成（腾讯云 HMAC-SHA1、阿里云 TC3-HMAC-SHA256），密钥只出现在你本机内存与 localStorage 中。

## 本地存储与 origin

浏览器按 **协议 + 主机 + 端口** 隔离本地存储。同一个地址打开，今天存的配置、术语库明天还在；
换地址（换端口 / 换域名 / `file://` 与 `http://` 互换）后历史数据看起来会「消失」（其实还在旧 origin 里）。

## 记录数据的本机上限

- 术语库导入记录与 TS 生成结果记录各自**最多保留最近 300 条**，按时间倒序，每页 10 条。
- 生成结果记录会把结果文件原样留在本机（步骤一为 Excel 转 base64、步骤二为 `.ts` 文本），方便日后重新下载。
  受浏览器存储容量限制有两条上限：**单条 ≤ 512 KB、全部记录合计 ≤ 2 MB**；
  超出上限时最旧的记录**只保留统计**，其「下载」会提示已不在本机留存，重新生成一次即可。

## 备份与迁移

- **术语库与规则库都可以导出 XLSX**，到新机器**导入**即可（导入为全量覆盖，会先清空目标库再重建）。
- **配置页没有导出功能**：密钥、代理地址、请求间隔、额度设置等需要在新环境重新填一次（本机存储只在本机有效）。
- 两类记录（术语库导入记录 / 生成结果记录）在操作栏都提供：
  - **明细** —— 导出该次的比对 / 生成明细（结果汇总 + 详细记录两张工作表）；
  - **下载** —— 取回该次操作的**原始文件本身**（导入记录＝当时导入的 XLSX；生成记录＝当时生成的结果文件）。

## 彻底清除

浏览器里清空对应站点数据即可（`file://` 打开就删 `file://` 相关数据；内网部署就删对应站点）。
删除 `ts-translate.html` 文件本身即完成卸载，无残留服务、无开机自启、无注册表写入。

## 注意事项

- 密钥属于敏感信息，**不要**把填过密钥的浏览器数据同步到公共账号。
- 团队协作：分发干净的 HTML，各自填自己的密钥，术语库与规则库用 XLSX 共享。
