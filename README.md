# TS 翻译专家

**一个 HTML 文件搞定的离线翻译工作台。** 面向 Qt / TypeScript `.ts` 语言文件的批量翻译：抽取待翻条目 → 自动机翻 → 术语与规则校正 → 回填生成翻译后的 `.ts`，一条龙做完。

零后端、零安装，双击即用；所有数据只留在你自己的浏览器里。

> 页面版本 **v1.3.0** · 单文件 HTML（约 1.4 MB） · Chrome / Edge / Firefox

---

## 一、核心能力

| 能力 | 解决什么 |
|---|---|
| **文本翻译** | 随手翻一段话，自动套用术语库与规则库，并高亮标出命中的术语与规则 |
| **术语库** | 多语种对照表（内置 13 个语种），保证专业词翻译前后一致；支持 XLSX 导入 / 导出 |
| **规则库** | 规定哪些内容**不翻译**（标签、占位符、数字、网址…）、哪些**照指定翻**；内置 5 条默认规则 |
| **TS 翻译** | 两步骤批量处理 `.ts`：一键导出 Excel（自动机翻）→ 校好译文 → 回填生成新的 `.ts`；支持多线程并发加速（1～8） |
| **生成结果记录** | 每次生成都留档：成功 / 失败 / 跳过三态对账，可看明细、可下载该次结果文件 |
| **备份与恢复** | 一键把四页数据备份到你指定的文件夹（文件名带时间戳），换机器「导入备份」复原 |

翻译服务五选一：**阿里云 / 腾讯云 / 百度 / 有道 / AI 大模型**（OpenAI 兼容）——浏览器直连，密钥不出本机。

## 二、快速开始

1. **打开** —— 双击 `src/ts-translate.html`。
2. **配置** —— 到「配置」页选一个翻译服务、填账号信息，点「测试连接」确认可用；顺手在最下方「备份与恢复」选定备份文件夹并点「立即备份」留一份。推荐**阿里云**或 **AI 大模型**（无需额外设置）。
3. **准备** —— 配置术语库和规则库，可以有效提高翻译质量。
4. **干活** —— 翻一段文字用「翻译」页；翻语言文件用「TS 翻译」页：**步骤一** 导入 `.ts` 生成 Excel（自动机翻）→ 人工校对 `Target` 列 → **步骤二** 上传 Excel 回填生成翻译后的 `.ts`。

更完整的说明见页面内置的「**使用说明**」页，或 `docs/` 下的文档：
[快速开始](docs/01-快速开始.md) · [功能说明](docs/02-功能说明.md) · [数据与隐私](docs/04-数据与隐私.md)

> **两种做法**，都走同一套「步骤一 → 步骤二」，区别只在 Excel 里 `Target` 列的译文由谁产生：
>
> 1. **机器翻译** —— 配好翻译服务 → 步骤一自动机翻 → 人工复核 `Target` 列 → 步骤二回填 `.ts`；
> 2. **人工翻译** —— 步骤一导出 Excel → 交译员**只填 `Target` 列** → 步骤二写回 `.ts`；
>
> ⚠️ **机翻产出的是初稿，可能有错译 / 漏译、术语偏差、占位符被破坏，回填前必须人工复核**（优先核对含占位符/标签的行、术语库命中的行、长句），复核要点见 [快速开始](docs/01-快速开始.md#机翻结果必须人工复核) 与「使用说明」页 7.7 / 7.8；拿不准的行把 `NeedTranslate` 改成 `0`。

## 三、数据与隐私（必读）

- **数据只在本机**：配置与密钥、术语库、规则库、导入 / 生成记录、片段译文缓存全部保存在**你自己的浏览器**里（localStorage / IndexedDB），不上传任何服务器；只有翻译请求由浏览器**直连**你配置的服务商。
- ⚠️ **清空浏览器缓存 / 清除站点数据会删除全部数据，且无法恢复。** 清理缓存、重装浏览器或换机器前，请先在「配置」页「**备份与恢复**」选定备份文件夹并点「立即备份」（不做自动备份），或到「术语库」「规则库」页用「**导出 XLSX**」备份。
- **文件本身零数据**：这个 `.html` 里不含任何用户数据，发给谁、谁打开都是干净的出厂状态。

详见 [数据与隐私](docs/04-数据与隐私.md)。

## 四、常见问题

**Q：能直接用 `file://` 打开吗？**
能跑，但部分浏览器会限制云接口跨域与本地存储，推荐放到本地静态服务 / 内网服务器使用。

**Q：翻译总是「连接失败」？**
先点配置页「测试连接」看诊断结论。多数是账号信息没填全，或百度 / 有道 / 腾讯云未配「代理地址前缀」；最省事是改用**阿里云**或 **AI 大模型**。

**Q：换电脑后数据怎么迁移？**
旧机器「备份与恢复」选定文件夹并点「立即备份」→ 把该文件夹带到新机器 → 打开本页「导入备份」即可整体复原；也可术语库与规则库「导出 XLSX」再导入。
