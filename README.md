# TS 翻译专家

一个**完全离线、零后端**的 Qt / TypeScript `.ts` 翻译工作台 —— 整个应用就是**一个 HTML 文件**，双击即用，不需要安装任何环境。

从 `.ts` 抽取待翻条目 → 批量机翻 → 术语与规则校正 → 回写生成翻译后的 `.ts`，一条龙做完。

> 页面版本 **v1.0.0** · 单文件 HTML 约 1.4 MB · 无任何后端服务 · 用户数据全部留在本机浏览器

---

## 一、它解决什么问题

| 环节 | 手工做法的痛点 | 本工具 |
|---|---|---|
| 抽取待翻 | 在 Qt Linguist 里逐条找 `unfinished` | 按状态配置「翻译范围」，一键导出成 Excel（每个 `.ts` 一张表） |
| 批量机翻 | 逐条复制进网页翻译器 | 阿里云 / 腾讯云 / 百度 / 有道 / AI 大模型 五类服务批量直连，密钥不出本机 |
| 术语统一 | 靠人肉记忆与全局替换 | 术语库（多语种 + 逐条大小写规整）在翻译前后自动套用 |
| 格式守护 | 占位符 `%1`、`${VAR}`、`<br/>` 常被翻坏 | 正则规则库在译前保护、译后还原 |
| 回写 `.ts` | 手工粘贴易串行、易破坏 XML | 按上传的 Excel 回填生成 `.ts`，成功 / 失败 / 跳过三向对账 |

## 二、启动方式：双击即用

双击 **`src/ts-translate.html`**，用 Chrome / Edge / Firefox 打开即可。

- 该文件是**纯静态资源**，也可以直接放到内网静态服务器 / 网盘 / 协作平台共享。
- 把它发给任何人，对方打开都是**干净的出厂状态**（示例数据只在自己的浏览器里生成，不随文件走）。
- 部分功能（云接口直连、本地存储）在 `file://` 下有浏览器策略限制，推荐放到本地静态服务或内网服务器使用，详见 [常见问题](#七常见问题)。

## 三、功能一览

### 配置页

- **五类翻译服务**：阿里云翻译（可直连，默认）/ 腾讯云翻译 / 百度翻译开放平台 / 有道智云翻译 / AI 大模型翻译（OpenAI 兼容）。按所选服务动态显示对应字段。
- **剩余免费额度**：本机计量，按实际送进接口的字符数扣减，总额度可改、每月自动清零、可手动清零。
- **代理地址前缀**：仅对必须走代理的服务（百度 / 有道 / 腾讯云）显示，用于绕开浏览器跨域限制。
- **请求间隔**：批量翻译时每条之间的等待毫秒数。
- **保存配置 / 测试连接**：测试连接会给出诊断结论，而不是干巴巴的「失败」。

### 翻译页

- 源语言 ⇄ 目标语言互换，单段文本翻译（`Ctrl+Enter`）。
- **实时高亮预览**：源文按「特殊词条 / 正则保护片段 / 术语库」三类着色，译后按同样口径标注。
- **命中统计表**：命中词条 / 规则名称、来源类型、出现次数；支持搜索、按来源类型筛选、刷新、分页。
- 字符数计数；当天 / 当月已翻译字符数记账（用于免费额度展示）。

### 术语库

- 多语种对照表：内置 13 个语种（`zh,en,ru,es,pt,fr,de,ja,ar,vi,ko,it,th`），可自由增删语种，点语种标签即显示 / 隐藏对应列。
- 表头全选框支持**跨页全选**（选中符合当前筛选条件的全部数据，翻页后保持）。
- 逐条 **大小写规整** 开关（独立的「大小写规整」列，位于操作列左侧）。
- **一键翻译**：后台任务批量翻译词条原文，已有译文不覆盖，进度显示在右下角悬浮条上。
- **导入 / 导出 XLSX**：表头为 `Term` + 各语种列 + `Casefix`；导入为**全量覆盖**（导入前弹覆盖确认，写明清空条数与警告），导入后生成一条比对记录。
- **术语库导入记录**：按 `Term` 列逐条比对，记录「新增 / 删除 / 更新 / 跳过」四个计数；可看「明细」、可下载该次导入的原始文件。

### 规则库

- **特殊词条（强制替换）**：命中即替换为指定译文，不送接口；支持忽略大小写、启用 / 停用、批量操作。
- **正则规则（不翻译的片段）**：命中内容原样保留，不做大小写规整；支持空格规整、启用 / 停用、批量操作、导入导出，以及**恢复默认规则**。
- **内置 13 条默认正则**：HTML 标签、大括号 / 百分号 / 美元 / 方括号四类占位符、纯数字、数字+百分号、数字+单位、日期、邮箱、URL、UUID、孤立符号。这套默认规则带**版本戳**，官方更新后打开页面会自动整组替换（替换前备份，不影响你的特殊词条）。
- **大小写规则**：翻译结果全部小写（默认开启）/ 句子首单词首字母大写 / 名词词组每词首字母大写，附实时测试框。
- **规则测试**：输入原文即可预览切片结果，高亮排版与翻译页**完全一致**。

### TS 翻译（两步骤）

- **翻译范围**：四个开关分别对应 `<translation>` 的四种状态 —— 未翻译 `unfinished`（默认勾选）、已废弃 `vanished`、已有译文、空白无标记。两个步骤共用同一套设置。
- **步骤一 · `.ts` → Excel**：多选 `.ts` 或选择文件夹 → 每个 `.ts` 生成一个 Excel（`原文件名_14位时间戳.xlsx`），行数恒等于该文件的条目总数，列固定为 `Source / Translate / Target / Type / NeedTranslate / Key`。已配置接口时先自动机翻。
- **步骤二 · Excel → `.ts`**：上传填好 `Target` 的 Excel（可多选 / 选文件夹）→ 按 `NeedTranslate` 列回填，输出与原 Excel 同名的 `.ts`。
- **默认下载路径**（两个步骤各自独立）：授权一个目录后文件直接写入，不再弹保存窗口。
- **生成结果记录**（两个步骤各一张表）：结果文件、生成时间、成功 / 失败 / 跳过三态统计；可看「明细」、可下载**该次生成的结果文件本身**。
- **悬浮进度条**：全站唯一的进度显示，两个步骤与术语库一键翻译共用，可随时「停止」。

### 使用说明页

内置完整手册（面向使用者，随版本更新），带常驻目录与回到顶部按钮。

## 五、数据与隐私

- **这个 `.html` 文件里不含任何用户数据。** 把它发给谁，谁打开都是干净的出厂状态。
- 密钥、术语库、规则库、导入记录、生成记录只存在**你自己的浏览器**里（`localStorage` / `IndexedDB`），不随文件走，也不上传到任何服务器。
- 翻译请求由你的浏览器**直接发往所选云厂商**（或你自建/自填的地址），本工具不做中转、不留日志。
- 换机器：术语库与规则库都可以**导出 XLSX**、到新机器**导入**；**配置页没有导出功能**（密钥与额度设置需要在新环境重新填一次）。

详见 [docs/04-数据与隐私.md](docs/04-数据与隐私.md)。

## 六、开发

页面是原生 HTML + CSS + ES5 风格 JS，业务代码统一挂在 `ZTW.*` 命名空间下，**没有构建步骤**：

```bash
# 改完开发主本后，把页面同步进仓库镜像
python scripts/sync-src.py

# 跑冒烟测试
cd tests/jsdom
npm install
npm test          # 37 项：版本 / 页签 / 术语库 / 规则库 / TS 两步骤 / 生成记录 / 帮助文档 / 全新实例
```

页面结构（自上而下）：`<style>` 全部样式 → 页头与页签 → 六个 `<section class="tab">` → 弹窗容器 → 业务 `<script>` → 帮助正文（`<script type="text/markdown" id="help-src">`）→ 启动块。

改动注意事项：

- 版本号是**单点**：`ZTW.VER`（脚本）与 `<code id="ver">`（页头）、`ZTW.VER_DATE` 三处同步。
- 默认规则（`DEFAULT_RULES.regexes`）改动后必须把 `RULES_DEF_VER` 加一，否则老浏览器不会感知改版。
- 任何用户数据都**不允许写回 `.html` 本体**，源码里只应有出厂常量与库代码。

## 七、常见问题

**Q：能不能直接用 `file://` 打开 HTML？**

能跑，但部分功能会受限：① `file://` 的 origin 是 `null`，云翻译接口的 CORS 可能被拒绝；② 各家浏览器对 `file://` 的本地存储策略不一致。建议放到本地静态服务或内网服务器使用。

**Q：翻译一直报「连接失败 / 网络请求失败」？**

先点配置页的「测试连接」看诊断结论。多数情况是账号信息没填全，或用了百度 / 有道 / 腾讯云却没配「代理地址前缀」。最省事的做法是改用**阿里云**或 **AI 大模型**（这两家可直连）。

**Q：术语库导入后原来的词条不见了？**

导入是**全量覆盖**：先清空当前列表，再按表格逐行重建，且不做去重合并。导入前会弹确认框写明清空条数与警告，确认后才执行。

**Q：生成的记录里「下载」拿不到文件了？**

记录会把结果文件原样留在本机（单条 ≤ 512 KB、全部记录合计 ≤ 2 MB）。超出上限时最旧的记录只保留统计，「下载」会提示已不在本机留存 —— 重新生成一次即可。
