# jsdom 冒烟测试

在 Node 里直接加载单文件页面，断言核心结构与行为。不需要浏览器、不需要打包。

```bash
cd tests/jsdom
npm install
npm test
```

`smoke.js` 覆盖：

| 组 | 断言内容 |
|---|---|
| [0] 分发文件零数据 | 源码中不含任何预置用户数据字面量；记录表空态 `colspan="7"` |
| [1] 加载 | `window.ZTW` 挂载、无脚本错误、版本号形如 `x.y.z`、标题正确 |
| [2] 页签 | 6 个页签及其顺序 `config,translate,glossary,rules,ts,help` |
| [3] 术语库 / 规则库 | 写入 → 回读一致；确实落入 localStorage；磁盘 HTML 未被改动 |
| [4] TS 生成记录 | 步骤一 / 步骤二表头固定七列，`跳过`列常显 |
| [5] 帮助文档 | 内置说明书存在，并写明"文件本身不含用户数据" |
| [6] 全新实例 | 另起一个 jsdom 实例（模拟把文件发给别人）：生成记录为空、术语库干净 |

退出码：全部通过 `0`，有失败 `1`。

> 只依赖 `jsdom`，页面内置的 SheetJS 随页面一起加载，所以 Excel 相关功能在 jsdom 里也能跑。
